GAME REPORT WORKFLOW

Add one Markdown file per game to this folder in GitHub. The filename must exactly match the game ID in scores.html, followed by .md.

Example:
2026-09-11-nc-state.md

Use this format:
---
title: Hokies open the season against NC State
summary: A short description for the report header.
date: 2026-09-11
---

Write the complete game recap here.
